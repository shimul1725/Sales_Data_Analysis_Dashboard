# Sales Data Analysis Dashboard

---

## 📖 Project Overview & Business Objectives

The **Sales Data Analysis** project is a complete end‑to‑end data‑analytics solution built around the classic **Superstore Sales** dataset.  It demonstrates how a data analyst can:

1. **Ingest** raw CSV data and store a cleaned version in a SQLite database.
2. **Explore** the data with exploratory data analysis (EDA) – statistical summaries, correlation matrices, and visual insights.
3. **Build** an interactive, **dark‑themed** Streamlit dashboard that lets business users slice & dice the data in real time.
4. **Generate** actionable business insights such as top‑selling products, profit margins, regional performance, and simple sales forecasts.
5. **Export** clean data for downstream consumption (e.g., Power BI).

The primary business goal is to provide a **single source of truth** for retail sales performance, enabling stakeholders to make data‑driven decisions on inventory, pricing, and customer segmentation.

## 🗄️ Database Schema & Data Pipeline

### SQLite Schema (`sql/schema.sql`)
```sql
CREATE TABLE IF NOT EXISTS sales (
    row_id INTEGER PRIMARY KEY,
    order_id TEXT,
    order_date DATE,
    ship_date DATE,
    ship_mode TEXT,
    customer_id TEXT,
    customer_name TEXT,
    segment TEXT,
    country TEXT,
    city TEXT,
    state TEXT,
    postal_code TEXT,
    region TEXT,
    product_id TEXT,
    category TEXT,
    sub_category TEXT,
    product_name TEXT,
    sales REAL,
    quantity INTEGER,
    discount REAL,
    profit REAL
);
```

### Data Pipeline (high level)
1. **Acquire** – raw CSV placed in `data/raw/`.
2. **Audit & Clean** – `src/data_cleaning.py` performs missing‑value handling, type conversion, outlier checks, and writes `Superstore_cleaned.csv` to `data/processed/`.
3. **Load** – `src/database.py` creates/opens `sales_analysis.db` and uses `pandas.to_sql` to import the cleaned data into the `sales` table.
4. **Analyse** – SQL scripts in `sql/` and Python notebooks generate statistical insights and visual artefacts.
5. **Visualise** – `dashboard/app.py` reads directly from the SQLite DB (or CSV fallback) and presents an interactive, dark‑themed UI.

## 🚀 Getting Started (local setup)

1. **Clone the repository** (or copy the folder) to your machine:
   ```bash
   git clone https://github.com/your‑username/Sales_Data_Analysis.git
   cd Sales_Data_Analysis
   ```

2. **Create and activate a virtual environment** (recommended):
   ```bash
   python -m venv venv
   # Windows PowerShell
   .\\venv\\Scripts\\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. **Install the required packages**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Download the Superstore dataset** from Kaggle (or any public source) and place the CSV inside `data/raw/`.
   ```text
   data/raw/Superstore.csv
   ```

5. **Run the data pipeline** – clean the data and load it into SQLite:
   ```bash
   python src/data_cleaning.py   # creates data/processed/Superstore_cleaned.csv
   python src/database.py        # creates data/sales_analysis.db
   ```

6. **Generate the Phase 5 visualisations (optional)**:
   ```bash
   python src/advanced_eda.py
   ```

7. **Launch the Streamlit dashboard**:
   ```bash
   streamlit run dashboard/app.py
   ```
   The dashboard will open in your default browser at `http://localhost:8501`.

8. **Export a screenshot of the dashboard** (optional, see the *Capture Dashboard* script below).

## 📂 Capture Dashboard Screenshot (automation)

A small helper script (`scripts/capture_dashboard.py`) uses **Playwright** to spin up the Streamlit app, take a high‑resolution PNG, and store it under `reports/dashboard_preview.png`.

```bash
# Install Playwright (first‑time only)
pip install playwright
python -m playwright install chromium

# Capture screenshot
python scripts/capture_dashboard.py
```

The script is idempotent – if the dashboard is already running it will reuse the existing server; otherwise it starts a temporary one, waits for the UI to be ready, captures the screenshot, and shuts the server down.
